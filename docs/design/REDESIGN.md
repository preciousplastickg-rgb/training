## 0. Как читать макеты

- Каждый `*.dc.html` — один экран iPhone 390 pt. Вёрстка — обычный HTML с инлайн-стилями: размеры, цвета, радиусы брать оттуда как есть.

## 2. Обязательные правила

1. Лайм, `--energy`, `--protein` — только фон и графика. Текст на лайме — `#111214`. Лайм как цвет текста — только на тёмном фоне.
2. Строки-кнопки (меню «+», настройки, списки): `width: 100%`, отступ 20–22 px слева и справа. Отступы задавать классом с большей специфичностью, чем глобальный сброс `button { padding: 0 }` (на макете меню из-за этого значки «прилипали» к краю — проверить в коде).
3. Текст не ближе 14 px к краю карточки; в сетках из трёх-четырёх кнопок — короткие подписи («Авто», не «Как в системе»).
4. Зоны нажатия ≥ 44, в тренировке ≥ 56. `prefers-reduced-motion` и safe-area — как в SPEC 9.

## 3. «Как делать» (`ExerciseSheet.tsx`) — макет `BHowTo`

### 3.1 Манекен: группы мышц видны формами

`src/components/body/Mannequin.tsx`, функция `Body`: в каждом слое сразу после заливки кожи и до блока свечения добавить чёткие формы мышц, обрезанные по телу:

```tsx
<g clipPath={`url(#${gid}-clip-${layer})`}>
  {glow.filter((pl) => layerOf(pl) === layer).map((pl) => {
    const h = hl(pl.muscles);
    return (
      <polygon
        key={'a' + pl.key}
        points={ptsAttr(pl.pts)}
        fill={h ? h.color : '#FFFFFF'}
        fillOpacity={h ? 0.92 : 0.07}
        stroke={h ? '#0E2A19' : 'var(--body-line)'}
        strokeOpacity={h ? 0.55 : 0.9}
        strokeWidth={0.7}
        strokeLinejoin="round"
      />
    );
  })}
</g>
```

Свечение (`blur` / `core`) оставить. Цвета мышц — прежние зелёные `--m-primary` / `--m-secondary` (не лайм): это анатомия, а не интерфейс.

### 3.2 Карта мышц с выносками

Вместо двух карт по 56 px — одна `MuscleMap` 130 × 286:
- вид — `back`, если хотя бы одна основная мышца есть в `posteriorData`, иначе `front`;
- центр группы считать в коде: среднее точек полигонов группы с x > 50 (правая половина), × 1,3;
- выноска: точка 3,5 → линия до x = 146 → подпись с x = 152. Основные — сплошная `--m-primary`, подпись 15/700 зелёная; помогающие — пунктир 3/3, подпись светлее;
- подписи по y сверху вниз, шаг ≥ 38 px, при наложении сдвигать вниз;
- вторая строка подписи — новое необязательное поле `Exercise.muscleRoles?: Partial<Record<Muscle, string>>` в `src/data/exercises.ts`. Заполнить для всех 19 упражнений, 2–4 слова (`barbell_rdl`: hamstrings «главная работа», glutes «разгибают таз вверху», lower_back «держит спину прямой», upper_back «держит лопатки сведёнными»);
- легенда над картой: «● основные ● помогают».

### 3.3 Остальное

## 6. Цель по весу (решено 6 ноября 2026)

- Формулы проверены и верны: % жира — ВМС США (Hodgdon, Beckett 1984), метрическая версия, как в `src/domain/body.ts`; цель — `сухая масса / (1 − цель% / 100)`. Код не трогать.
- Замер один (без трёх повторов).
- Цель при старте — результат формулы, показывать как ориентир «≈ 72 кг» (округление до целого). В первом запуске выбор «Оставить 73» убрать; вручную цель меняется в настройках.
- Пересчёт на контрольных точках: записаны талия и шея → новая цель от текущего среднего веса. Разница ≥ 0,5 кг → карточка на «Сегодня» «Цель уточнена: ≈ 72 кг (было ≈ 73). Принять · Оставить». Логика — чистая функция в `src/domain/body.ts` с тестом.
- Подробности — SPEC 1, 5.5, 6.8 (уже поправлены).
- На макетах B цель уже «≈ 72»: путь 42 %, «−3,8 из 9,1», прогноз 20 марта.
